\# Machine Learning Module



This module contains the machine learning pipeline

for the Hybrid ML-Based Intrusion Detection System.



\## Pipeline



1\. Dataset Loading

2\. Data Cleaning

3\. Encoding and Scaling

4\. Exploratory Data Analysis

5\. Train/Validation/Test Split

6\. Baseline Models

7\. FT-Transformer

8\. Autoencoder

9\. Hybrid Model

10\. Model Evaluation

11\. ML Inference

12\. Backend Integration



\## Datasets



\- CICIDS2017

\- CIC-IoT2023



\## Models



\- Baseline ML Models

\- FT-Transformer

\- Autoencoder
